# 수락 테스트 (기획 Definition of Done)

구현 후 검수·구현자 자체 검증은 **이 10개만**으로 한다.

1. 회사 관리자가 직원 2명 등록, 1명 휴직 처리 → 휴직자는 지정 목록에서 제외.
2. 번호로 검색 → 없음 → 최소 필드로 고객 저장 → 장비 1대 등록 → AS 접수 → 직원 A 지정.
3. 같은 번호로 재검색 → 기존 고객, 장비, 방금 티켓이 보임.
4. 담당을 A→B 변경 → 두 직원 카드와 티켓 타임라인에 남음.
5. 동일 장비로 20일 후 신규 AS → 재고장 표시.
6. 사진 없이 완료 → 저장되고 사진미비 목록에 등장.
7. 완료 후 사후확인 → 종결.
8. 고객 전화 변경 → 옛 번호로도 검색되거나 이력에서 확인.
9. 퇴사 직원 과거 티켓이 깨지지 않음.
10. (스키마) 다른 `company_id` 데이터가 쿼리에 안 섞일 구조.
