# 기획 검수 결과 (빌더 투입 전)

> **비정본.** 제품 정본은 [`HQ-BUILDER-SPEC.md`](HQ-BUILDER-SPEC.md).  
> 이 파일의 급여 제외 등 옛 항목은 따르지 말 것.

**역할:** 기획 검수 (역사 기록)  
**판정:** 조건부 통과 (당시)  
**구현:** Grok Builder(구현자) 몫. 검수자는 코드·화면·서버를 만들지 않음.

방향(본사 SaaS = CRM + AS + 인력배정)은 맞다.  
고정값을 잠그지 않으면 빌더가 구멍을 메우다 **단순 AS 게시판**이 된다.

## 1. 잠근 제품 정의

> 단일 테넌트부터 켜는 본사 운영 SaaS.  
> 사용자 = 회사 직원.  
> 핵심 객체 = 회사 / 조직 / 직원 / 고객 / 장비 / 티켓.  
> 고객이 직접 가입하는 B2C 앱이 아님.

빌더가 하면 안 되는 해석
- 소비자용 세차 예약 앱
- 기사 전용 앱 1차 포함
- 재고·회계·급여 ERP
- 카카오 알림/문자 연동 1차 필수

1차 채널: **본사 PC 웹**. 권한 모델만 기사 역할을 예약.

## 2. 빌더가 추측하면 실패하는 지점 (고정 권고)

### A. 테넌시
- 모든 업무 테이블에 `company_id` 필수
- 조회는 항상 테넌트 스코프
- 1차 배포는 테넌트 1개여도 스키마는 멀티테넌트
- 슈퍼어드민(플랫폼)과 본사관리자를 섞지 말 것

### B. 고객 등록
- 전화 중 최소 저장: 유형, 표시명, 대표번호, 주소(한 줄)
- 저장 전 대표번호 중복 검색 필수
- 삭제 없음. `active | dormant | closed`
- 번호·주소 변경 시 이력
- 고객 담당 직원(`account_owner`)과 AS 주담당(`assignee`)은 **다른 필드**

### C. 직원 (HR로 팽창 금지)
1차 포함: 프로필, 역할, 소속, 재직상태, 권역·숙련 태그, 열린 배정/처리 이력, 휴무 메모(날짜 단위)  
1차 제외: 급여, 주민번호, 연차 정산, 평가  
지정: 주담당 1명만 / 퇴사·휴직자 신규 지정 불가·과거 건 유지 / 재지정 이벤트 로그 필수 / 미지정 큐 = 1급 화면

### D. AS 상태 전이 (자유 select 금지)

| From | To | 조건 |
|---|---|---|
| 접수 | 배정됨 | 주담당 필수 |
| 접수 | 배정대기 | 담당 없음 |
| 배정대기 | 배정됨 | 주담당 |
| 배정됨 | 출동중 / 보류 / 취소 | |
| 출동중 | 수리중 / 부품대기 / 완료 | |
| 수리중 | 부품대기 / 완료 | |
| 완료 | 사후확인 | |
| 사후확인 | 종결 / 재오픈 | |
| 종결 | 재오픈만 | |
| 아무 상태 | 취소 | 사유 필수 |

완료 시 사진: **없어도 완료 가능, 미첨부 경고 + 대시보드 미비 목록** (강제 금지 권고)

### E. 사진
- before 5, after 5
- 메타: 슬롯번호, 유형, 업로드자, 시각
- 용량·포맷·번호판 정책은 추후

### F. 전화 접수
- 1차 = 수신번호 수기/붙여넣기 + 고객 검색 + 콜 로그
- CTI 범위 밖
- 콜 로그는 고객·티켓 양쪽에 attach

### G. 스케줄
- 기사×날짜 목록 + 방문일시
- 동일 시간 겹침 = **경고만** (차단 아님)
- 드래그 캘린더 = 2차

## 3. IA (이 메뉴 밖으로 화면 늘리지 말 것)

1. 로그인  
2. 대시보드  
3. 접수 데스크 (콜 + 신규 AS)  
4. AS 보드 (큐/필터/티켓 상세)  
5. 스케줄  
6. 고객  
7. 장비  
8. 직원  
9. 사후함  
10. 설정  

티켓 상세 = 보드에서 여는 **한 장**. 고객·직원 = 허브 페이지.

---

## 4. 소유 방향

- Company 1 — N Org, User, Customer, Ticket
- Customer 1 — N Equipment, Ticket, CallLog
- User 1 — N Ticket(as assignee)
- Ticket 1 — N Event, Photo, PartUsed(옵션), FollowUp

실패 패턴: 고객명/직원명 문자열만, 장비 마스터 우회를 기본으로 둠.  
장비: **필수**. 미등록이면 고객 카드에서 장비 먼저 추가.

## 6. SLA 기본값 (설정에서 변경 가능)

- 긴급: 2시간 미배정 = 지연
- 일반: 24시간 미배정 = 지연
- 방문일 지난 미완료 = 지연
- 완료 후 3일 사후미확인 = 사후함
- 재고장: 동일 equipment_id, 종결·완료 후 30일 이내 신규 접수

대시보드 카드: 오늘 콜 / 오늘 방문 / 미지정 / 지연 / 부품대기 / 사진미비 / 오늘 완료 / 재고장(30일)

## 7. 권한

- 본사관리자: 마스터 + 상태성 삭제 대체(퇴사처리 등)
- 상담: 고객·티켓 생성, **주담당 지정 가능**(검수 권고)
- 배차: 재지정·일정 특화
- 기사: 1차 UI 비노출, role 코드만 존재
- 조회: GET만
- 물리 삭제 1차 비허용
