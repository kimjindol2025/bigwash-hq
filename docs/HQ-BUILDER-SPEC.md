# 빌더 지시서 — bigwash-hq (정본)

대상 저장소: `https://github.com/kimjindol2025/bigwash-hq`  
브랜치: `main`  
역할: 본사 앱만 완성한다. 기획 검수자는 코드 안 짠다.

이 문서가 `docs/HQ-BUILDER-SPEC.md` 정본이다. 대화 원문·옛 REVIEW·OPEN-DECISIONS·README의 고객포털 설명보다 **이 문서가 위**다.

---

## 0. 제품

본사 운영 SaaS. 전화가 입구. 고객 앱 없음.

```
전화 → 고객 CRM → (기본) 출장
 → 직원 1..N 지정(용병은 본사만 기록)
 → 권역 출장비 + 사내몰 부품 N
 → 견적/명세(PDF·이미지)
 → 직원앱은 다른 저장소/나중에
 → 본사는 사진·일지·완료·정산버튼 수신
 → 내부정산(출장·수리·경비·급여) + 엑셀 보고
```

앱 분리
- **본사 앱** = 이 레포. PC + 모바일(같은 UI, 전화 데스크 포함).
- **직원 앱** = 만들지 말 것. 데이터 필드만 받을 준비.
- **용병** = 계정·앱 없음. 본사 수기.

로그인: 아이디+비밀번호. 전화 로그인 없음.

테넌트: 모든 업무 테이블 `company_id`. 물리 삭제 없음.

## 1. 지금 레포에서 먼저 할 일 (차단)

저장소가 옛 ‘고객 AS 접수’와 새 HQ가 섞여 있다. 아래를 안 하면 기능 추가 금지.

1. README를 본사 HQ만으로 다시 쓴다. 진입점 `/hq/login.html`.
2. `public/register.html`, `public/customer.html` → `legacy/public/` 이동. 라우트 404.
3. 비인증 `POST /as/register`, `GET /customer/requests` 본사 서버에서 제거 또는 레거시 포트로만.
4. `COMPLETION_REPORT.md`, `PHASE2_ROADMAP.md` 상단에 `LEGACY — 고객접수 제품. 본사 정본 아님` 표시.
5. `npm test`가 옛 44테스트로 HQ 완료처럼 보이지 않게. HQ는 `npm run test:hq19` + §20 추가분.
6. 문서의 `admin / admin123` 실사용 안내 삭제. 시드는 최초 로그인 변경 강제 또는 env만.
7. `docs/HQ-BUILDER-SPEC.md`를 이 문서 전문으로 교체.
8. `docs/OPEN-DECISIONS.md`를 §19 확정표로 교체.

레거시 `server.js`, `v9/`, `legacy/`는 실행 기본 경로에서 분리. `npm start` = HQ AFJ만.

## 4–18

상세는 제품 요구사항 원문과 동일 (역할, 고객, 장비, 구매확정·무상, 전화데스크, 티켓, 배정·스케줄, 권역, 사내몰, 견적명세, 수신값, 정산, 대시보드, 보고, 전이).

### 구매확정 `hq_customer_purchases`
company_id, customer_id, product_id, fulfill_type(`ship`|`install`), confirm_date, equipment_id?, note  
무상: confirm_date + 365일 (장비 warranty_until로 판정 금지)

### 배정 `hq_ticket_assignees`
ticket_id, user_id nullable, contractor_name, kind, is_primary, day_pay_amount

## 19. 오너 확정 (더 묻지 말 것)

- 회계: 내부 정산만  
- 급여: 기본+수당/공제 수기 (정규직)  
- 출장비: 지역별 단가. 수리비=자재+난이도  
- 출퇴근: 본사 대행+휴무. 직원 타각 없음  
- 완료보고서: 직원앱이 제출. HQ는 수신. 용병은 본사 대행  
- 운영비 항목: 임대·차량·부품·통신·기타  
- 보고: 화면+엑셀  
- 고객: B2B 기본, B2C 유형만 예약  
- 권한: 급여 경리, 경비 신청+승인  
- 돈 4종 전부 1차  
- 고객앱: 없음  
- 전화 기본 결과: 출장  
- 무상: 구매확정 1년  
- 구매: 본사 몰 선택 + 날짜 수기  
- 기점: 택배=발송일, 설치=설치일  
- 명세 계좌 한 줄, 도장 선택  
- 배정 1..N + 용병  
- 용병 보수: 당일 일지 수기  
- 용병 앱: 없음  
- 본사: PC+모바일, 전화데스크 포함  
- 로그인: 아이디+비번  
- 알림 1차: 앱 안만 (문자 없음)

## 21. 완료 정의

레거시 고객입구가 꺼지고, 구매확정·N배정·용병수기·실파일 명세·권역출장비가 본사 화면에서 한 줄로 이어지면 1차 끝.  
직원 앱을 이 레포에 넣는 순간 지시 위반이다.

## 명세 파일 1차 산출물

- `pdf_base64`: `%PDF` 매직의 실제 PDF 바이트
- `image_png_base64`: 세로 PNG 바이트 (`public/hq/assets/doc-portrait.png`)
- `content`: 동일 본문 + 계좌 한 줄 (양쪽 공통)
- `image_svg`: 세로 이미지 **추가 대체본** (카톡 등에서 SVG 필요할 때)
