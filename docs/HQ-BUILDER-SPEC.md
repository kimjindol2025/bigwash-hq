## 3–20

상세는 대화 원문과 동일. 수락 테스트는 §19.

### 수락 테스트 (§19)

1. 번호 없음 → 고객 최소저장 → 장비추가 → 출장 → 직원A 지정.  
2. 같은 번호 재검색 → 고객·장비·티켓 보임.  
3. 담당 A→B → 양쪽 직원카드·타임라인.  
4. 권역 변경 → 출장비 줄이 요금표대로.  
5. 상품 등록 후 (직원발행 가정) 명세 PDF/이미지 다운로드.  
6. 정산 미수 뱃지·미수 목록.  
7. 동일장비 20일 후 출장 → 재고장.  
8. 급여 수당공제 입력 → 월 엑셀에 총액.  
9. 경비 승인.  
10. 퇴사 직원 과거 티켓 유지, 신규지정 불가.
