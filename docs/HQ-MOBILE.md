# 본사 모바일 셸

기능은 1·2차 그대로다. 좁은 폭의 껍데기와, PC·모바일이 같이 쓰는 글색만 바꾼다.

## 토큰

```css
--bg:#070b14; --panel:#101827; --card:#182236; --line:#3d4f6e;
--text:#f3f7ff; --muted:#c5d4ea; --accent:#3de0c7; --danger:#ff8a95;
--warn:#ffc14d; --ok:#3ddc97; --info:#7aa2ff; --input:#0b1220;
```

본문·줄1·줄2·금액은 `--text`. `--muted`는 11px 라벨과 줄3 메타만. `#8fa3c1` 본문 사용 없음.

뱃지는 배경과 글이 한 쌍이다. 접수·배정대기는 갈색/노랑, 배정·출장·수리는 녹청, 완료·종결·완납·해당없음은 녹색, 미수·부분수금은 붉은 배경. 칩 active는 `rgba(61,224,199,.18)` 배경과 accent 글.

## 분기

| 폭 | 셸 |
|---|---|
| ≥ 980px | 왼쪽 사이드바 220px + 본문. ☰ 없음. 목록은 표. 티켓은 오른쪽 서랍 |
| < 980px | 상단바 56px(☰ · 현재 메뉴명 · 새로고침) + 스크롤 본문. 하단 탭 없음 |

중간 폭에서 사이드바를 줄여 메뉴를 두 줄로 두지 않는다.

## 드로어

왼쪽 85% 폭, 높이 100%, 배경 딤. 브랜드 → 기존 13메뉴 순서 → 맨 아래 이름/역할/로그아웃. 항목 높이 44px 이상. 바깥 탭, ESC, 메뉴 선택 시 닫힘. 열린 동안 본문 스크롤 잠금.

## 카드

PC 표 컬럼은 유지한다. 980 미만에서는 같은 칸을 카드로 보여 준다.

```
줄1  주이름(--text, 15px)            뱃지
줄2  보조 한 줄(--text)
줄3  메타(--muted)
```

출장 보드: 고객표시명 · 업무상태 · 정산 / 증상 / 담당이름(+N) · 방문일시 · 번호.

필터 칩은 가로 스크롤 한 줄이다. 버튼·입력 최소 높이는 44px.

## 화면

1. 로그인: 좌우 24px, 입력·버튼 44px, 위부터 배치해 키보드에 버튼이 고정되지 않음
2. 대시보드: 통계 2열. 전화/미지정/미수는 세로 전체 너비. 알림은 본문 맨 위 한 줄
3. 전화 데스크: 검색은 상단바 바로 아래 sticky. 출장/상담은 하단 sticky
4. 출장/티켓: 칩 한 줄 + 카드. 가로 스크롤 표 없음
5. 스케줄: 직원, 용병, 날짜, 시각, 조회, 용병등록 순. 미일정 부여도 카드
6. 고객: 검색 sticky. 저장 3버튼은 에디터 하단 sticky. 한 컬럼
7. 장비: 장비명 / 고객 / 위치 카드
8. 직원: 급여 숫자는 한 열. 용병 카드에 월급 없음
9. 사내몰: 이름, 유형, 판매가, 상태. 원가는 경리만
10. 권역: 이름과 출장비 카드
11. 정산: 미수|출장수금|경비|운영비 칩. 부분수금은 모달
12. 보고: 일/주/월 + 엑셀이 한 줄. 지표/값 두 열
13. 사후함: 재고장, 사진미비, 완료·미수 카드
14. 설정: 한 컬럼
15. 티켓 서랍: 모바일 하단 시트 88vh, 핸들과 닫기. 사진·일지·마감 유지

## 체크

390에서 13메뉴는 ☰ 안에만 있다. 980 이상에서 사이드바와 출장 7열 표가 돌아온다.
