# 오너 확정표 (더 묻지 말 것)

정본: `HQ-BUILDER-SPEC.md` §19

| 항목 | 확정 |
|------|------|
| 회계 | 내부 정산만 |
| 급여 | 기본+수당/공제 수기 (정규직) |
| 출장비 | 지역 단가. 수리비=자재+난이도 |
| 출퇴근 | 본사 대행+휴무. 직원 타각 없음 |
| 완료보고서 | 직원앱 제출, HQ 수신. 용병=본사 대행 |
| 운영비 | 임대·차량·부품·통신·기타 |
| 보고 | 화면+엑셀 |
| 고객 | B2B 기본, B2C 유형만 예약 |
| 권한 | 급여 경리, 경비 신청+승인 |
| 돈 4종 | 전부 1차 |
| 고객앱 | 없음 |
| 전화 기본 | 출장 |
| 무상 | 구매확정일 + 365일 |
| 구매 | 본사 몰 선택 + 날짜 수기 |
| 기점 | 택배=발송일, 설치=설치일 |
| 명세 | 계좌 한 줄, 도장 선택 |
| 배정 | 1..N + 용병 |
| 용병 보수 | 당일 일지 수기 |
| 용병 앱 | 없음 |
| 본사 | PC+모바일, 전화데스크 포함 |
| 로그인 | 아이디+비번 |
| 알림 1차 | 앱 안만 (문자 없음) |
